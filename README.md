# BadBank - Banking Application

## Description

BadBank is a simple banking application developed as a learning project. It helps users understand the basic concepts of a banking interface and web development.

## Motivation

The purpose of this project is to practice HTML, CSS, and JavaScript and learn how to develop and improve a banking application.
